# 与群友的情趣小插件

一个用于 AstrBot 的群聊互动插件。插件会在指定群聊中监听指定用户的发言，并按配置的概率随机触发预设回复。

## 功能特点

- 支持仅在指定群聊中启用
- 支持为不同用户配置不同回复内容
- 支持为同一用户配置多条回复并随机选择
- 支持自定义触发概率

## 安装方式

### 方式一：通过 AstrBot 插件市场安装

在 AstrBot 管理面板中搜索本插件并安装。

### 方式二：手动安装

进入 AstrBot 的插件目录：
- 点击右下角安装插件
- 选择从链接安装
- 将git链接粘贴上去点击安装即可

```bash
cd data/plugins
```

克隆本仓库：

```bash
git clone https://github.com/Xc-Star/astrbot_plugin_jokes_friends.git
```

重启 AstrBot 或在管理面板中重载插件。

## 配置说明

插件配置文件由 AstrBot 自动生成，可在管理面板中编辑。

### enabled_groups

启用回复功能的群聊列表。

只有群号在该列表中的群聊才会触发回复；如果为空，则不会在任何群聊中启用。

示例：

```json
[
  "123456789",
  "987654321"
]
```

### reply_template

回复模板列表，格式为：

```text
用户ID|回复内容1|回复内容2|回复内容3
```

说明：

- 第一段为目标用户 ID
- 后面的内容为该用户可触发的回复
- 多条回复之间使用英文竖线 `|` 分隔
- 触发时会从该用户配置的回复中随机选择一条发送

示例：

```json
[
  "1234567890|抓到你了！|今天也在水群吗？|快说点有意思的",
  "9876543210|群友出现！|你终于说话了"
]
```

### reply_probability

回复触发概率。

取值建议为 `0` 到 `1` 之间的小数：

- `1` 表示 100% 触发
- `0.5` 表示 50% 触发
- `0.3` 表示 30% 触发
- `0` 表示不触发

示例：

```json
"0.3"
```

### enable_whitelist_compare

预留配置项，目前暂未实现。

## 配置示例

```json
{
  "enabled_groups": [
    "123456789"
  ],
  "reply_template": [
    "1234567890|抓到 xx 了！快撅！|今天也逮到你了",
    "9876543210|群友上线！|你怎么又来了"
  ],
  "reply_probability": "0.3",
  "enable_whitelist_compare": false
}
```

## 使用效果

当满足以下条件时，插件会随机发送一条配置好的回复：

1. 当前群聊在启用群聊列表中
2. 发言用户在回复模板中配置过
3. 随机概率命中

例如，配置：

```text
1234567890|抓到你了！|今天也在水群吗？
```

当用户 `1234567890` 在启用的群聊中发言时，插件可能回复：

```text
抓到你了！
```

或：

```text
今天也在水群吗？
```

## 注意事项

- 群号和用户 ID 建议使用字符串形式填写
- 分隔符必须使用英文竖线 `|`
- 回复内容中如果包含 `|`，会被当作分隔符处理
- 如果配置的触发概率过高，可能会造成刷屏，建议根据群聊活跃度合理设置
